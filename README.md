# 🌌 ClientHub

**The Operating System for Modern Agencies.**

ClientHub is a premium, production-ready SaaS boilerplate designed for freelancers and agencies to manage clients, projects, and payments. It features a stunning dark-mode glassmorphic UI, org-based multi-tenancy, and a dual payment engine (Fiat + Crypto).

## ✨ Features

- **🎨 "Aura" UI:** Dark-mode glassmorphism, aurora mesh gradients, and smooth CSS animations. Zero blandness.
- **🏢 Org-Based Multi-Tenancy:** Built for teams. Users belong to Organizations, not just personal accounts.
- **💳 Dual Payment Engine:** 
  - **Flutterwave:** Accept Cards, Bank Transfers, and Mobile Money (Global + Africa).
  - **Coinbase Commerce:** Accept BTC, ETH, USDC, and 100+ cryptos.
- **📊 Tiered Billing:** Free, Pro, and Agency tiers with automated limit enforcement.
- **📁 Project Management:** Create projects, track milestones, and share file deliverables with clients.
- **🔐 Secure Auth:** Passwordless magic links via Supabase Auth.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router, Server Actions)
- **Database & Auth:** Supabase (PostgreSQL, RLS, Storage)
- **Styling:** Tailwind CSS (Custom Glassmorphism & Aurora utilities)
- **Payments:** Flutterwave API + Coinbase Commerce API
- **Deployment:** Vercel
